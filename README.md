# MackenzieGlaser.github.io — Portfolio Redesign

A redesigned personal portfolio for Mackenzie Glaser, built as a lightweight static GitHub Pages site.

## Files

- `index.html` — main one-page portfolio
- `resume.html` — print-friendly resume view
- `stylesheet.css` — full visual system and responsive styles
- `script.js` — mobile navigation, cursor glow, and active-section behavior

## Deploy

Replace the existing site files in the `MackenzieGlaser.github.io` repository with these files and push to the `main` branch. GitHub Pages will serve `index.html`.

The design uses Google Fonts (DM Sans + Fraunces) through a stylesheet import. Everything else is local/static and requires no build step.
