# Mackenzie Glaser — Personal Portfolio

Welcome to the source code for my personal portfolio website.

🌐 **View my website:**  
https://glaserm6.github.io/Personal-Website/

This website showcases my academic background, research experience, technical skills, and interests as a Computer Science student at Northern Kentucky University.

I am especially interested in the intersections between **computer science, data, statistics, machine learning, and interdisciplinary research**, with a particular interest in using computational and quantitative methods to explore problems in other fields.

## What You'll Find

- **About Me** — My academic background, interests, and research focus
- **Research** — My work on ThinkPilot and AI-based eye-tracking and gaze detection
- **Toolkit** — Programming, data analysis, machine learning, research, and quantitative skills
- **Education** — My Computer Science degree, Mathematics and Neuroscience minors, and academic achievements
- **Recognition** — Research presentations, scholarships, awards, and accomplishments
- **Beyond the Resume** — Campus activities, organizations, and interests outside of academics
- **Resume** — A print-friendly version of my current resume

## Design

The website uses a purple and lilac visual theme with subtle animations, glass-style elements, responsive layouts, and a whimsical orbital design while maintaining a professional presentation.
